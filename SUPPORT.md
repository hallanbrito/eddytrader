# Suporte — EddyTrader

## Antes de abrir uma Issue

Confira:

1. se está usando a versão mais recente disponível em [Releases](https://github.com/hallanbrito/eddytrader/releases);
2. se o MetaTrader 5 está conectado;
3. se **Algo Trading** está habilitado;
4. se existe somente uma instância do EddyTrader na conta;
5. se o problema também acontece em conta Demo;
6. os logs das abas **Experts** e **Journal** do MT5.

## Ao reportar um bug

Inclua, sempre que possível:

- versão do EddyTrader;
- build do MetaTrader 5;
- tipo de conta: Demo/Real;
- modo da conta: Netting/Hedging;
- estado FSM exibido no HUD;
- parâmetros usados;
- passos para reproduzir;
- retcode exibido, se houver;
- trecho relevante do Journal/Experts sem credenciais.

Nunca publique:

- senhas;
- tokens;
- chaves;
- dados de acesso;
- informações financeiras sensíveis.

## Segurança

Problemas que possam causar liquidação indevida, perda da proteção, falha de bloqueio ou recuperação incorreta devem ser descritos claramente como **risco de segurança operacional** na Issue.
